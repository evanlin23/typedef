# Synthetic font fixture

`IoctlTestFont.ttf` is an original test font with simple rectangular glyphs and
the family name `Ioctl Test Font`. It was generated with fontTools FontBuilder;
it contains no outlines copied from another font. Its purpose is to verify that
a font selected in the UI reaches LibreOffice and is embedded in the exported
PDF, including across consecutive conversions. It is not a fidelity reference.
