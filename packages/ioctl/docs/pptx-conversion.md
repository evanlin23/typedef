# Presentation export

The experimental browser PPTX converter has been retired. See the
[archive](archive/pptx/README.md) for its rationale, source snapshots, and results.

Export a PDF in PowerPoint (File → Export or Save As → PDF) for the closest match
to the original presentation. A free alternative is Google Slides with a Google
account: open the presentation, then File → Download → PDF Document (.pdf).
Google Slides requires an upload and may change fonts and layouts. Check the PDF
before adding it to the PDF Combiner. No method guarantees identical results for
all presentations.
